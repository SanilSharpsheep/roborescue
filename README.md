# RoboRescue

A browser game for grades 3–5 where kids build animal-inspired rescue robots (biomimicry) and use them on Texas flood missions. Built for the Congressional App Challenge.

Works on iPad, Chromebook, and phone. Water World has 3 missions; other worlds are coming soon.

## Run it
```
npm install
npm run dev
```
Build for the web with `npm run build` (output in `dist/`).

## How it works
Vite + plain JavaScript modules, Canvas 2D for the test run, WebAudio for sound. Progress is saved in the browser (localStorage). No accounts, no data collected.
